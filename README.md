# tokubechu.site

手書きの「とくべチュ、して」が斜めに流れる、静的サイトの最初の画面。

## ローカルプレビュー

```sh
cd ~/tokubechu.site
python3 -m http.server 4317 --bind 127.0.0.1 --directory public
```

http://127.0.0.1:4317 を開く。再読み込みすると最初から再生する。

## ファイル

- `public/index.html`: ページ情報と2つの文字素材
- `public/styles.css`: 配色、背景、文字の大きさ・通過方向・時間
- `public/intro.js`: 文字素材の読み込み後に演出を開始
- `public/assets/lettering/`: 見本の手書き文字に寄せて再生成した透過素材。元画像そのものの切り抜きではない。

## 演出

1. 約0.25秒、淡い背景だけを表示。
2. 「とくべチュ、」が右上から入り、中央で減速して左下へ抜ける。
3. 「して」が左上から入り、中央で減速して右下へ抜ける。

文字は各1.9秒、全体で約4.1秒。中央でなめらかに減速し、そのまま加速して抜ける。2つの素材は同じ元画像のピクセル倍率で表示し、文字の大きさをそろえる。フェードを合わせて1回だけ再生し、その後も背景はゆっくり動き続ける。端末の「視差効果を減らす」設定では文字を静止表示し、背景の動きを止める。

フレームワークとビルド処理は不要。Cloudflare Workers Static Assets では `public/` を配信対象にする。
