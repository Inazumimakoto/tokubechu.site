# tokubechu.site

手書きの「とくべチュ、して」が斜めに流れ、その後に＝LOVEの公式動画を横スクロールで楽しめる非公式の静的サイト。

## ローカルプレビュー

```sh
cd ~/tokubechu.site
python3 -m http.server 4317 --bind 127.0.0.1 --directory public
```

http://127.0.0.1:4317 を開く。再読み込みすると最初から再生する。

## ファイル

- `public/index.html`: ページ情報、文字素材、公式動画ギャラリー
- `public/styles.css`: 配色、背景、文字の大きさ・通過方向・時間
- `public/intro.js`: 文字素材の読み込み後に演出を開始
- `public/videos.js`: 横スクロール、動画選択、クリック時のYouTube埋め込み
- `public/assets/lettering/`: 現在は公式Dance Practice画像から実際の文字を切り出した透過PNGを使用。以前の生成素材も保管。

## 文字素材

[＝LOVE公式のDance Practice投稿](https://x.com/Equal_LOVE_12/status/1895466692593201565)の[原寸画像（2048×1152）](https://pbs.twimg.com/media/Gk4M6EOXcAABOac.jpg?name=orig)から白い書き文字を抽出。生成や描き直しはしていない。「チ」の長い終筆、離れた2本の細い線、筆の太さの変化を含め、元画像の形と字間を保持している。JPEGの輪郭は背景色を推定して半透明にし、背景の部屋と元の影を除去した。

- `title-original.png`（1448×274）：見出し用の全文。元画像の座標 `(332, 160)–(1780, 434)`。
- `title-first-original.png`（1032×274）と `title-second-original.png`（416×274）：全文を同じ高さのまま左右に分割したイントロ用素材。両方を同じ倍率で表示し、元の文字比率を保つ。

## 演出

1. 約0.25秒、淡い背景だけを表示。
2. 「とくべチュ、」が右上から入り、中央で減速して左下へ抜ける。
3. 前半が抜け始める頃（開始から約1.55秒）に「して」が左上から入り、中央で減速して右下へ抜ける。

文字は各1.9秒、全体で約3.5秒。中央でなめらかに減速し、そのまま加速して抜ける。「して」は前半と逆向きに−23〜−29度傾ける。公式画像から切り出した2つの素材を同じ倍率で表示し、濃い影と柔らかい影で読みやすくする。画像の読み込みと描画準備を待って開始し、タブが非表示の間は一時停止する。戻る操作でページがキャッシュから復元された場合も最初から再生する。画像の `decode()` が拒否されても、正常に読み込めていれば演出を省略しない。1回だけ再生した後、同じ文字の見出しと動画を上から順に表示。動画欄のレイアウトとサムネイル読み込みは演出後に始める。端末の「視差効果を減らす」設定ではイントロを省略して動画を表示し、背景の動きを止める。

## 公式動画

2026-10-11に[公式チャンネル @equallove_](https://www.youtube.com/@equallove_/search?query=%E3%81%A8%E3%81%8F%E3%81%B9%E3%83%81%E3%83%A5)の公開検索結果を最後まで確認し、曲に関連する通常動画17本を掲載。すべて公式投稿者と埋め込みHTMLを確認済み。限定公開・削除済み・検索結果に出ない動画は対象外。

- 通常動画17本：MV、Dance MV、Dance Practice、Position Shuffle、ライブ2本、FAN CAM10人分、Making。

動画一覧と公式YouTubeへのリンクは `public/index.html` の `video-slide` が単一ソース。カテゴリーのボタンは該当する最初の動画へ移動し、すべての動画を続けて横スクロールできる。遠くのサムネイルは遅延読み込みし、再生ボタンを押すまで埋め込みプレイヤーを読み込まない。

横スワイプ、トラックパッド、カテゴリーのボタン、PCの矢印ボタンで切り替えられる。動画欄にフォーカスすると左右キー・Home・Endも使える。サムネイルを押すと通常のYouTubeプレイヤーで再生し、別の動画に切り替えると再生中のプレイヤーを終了する。自動再生で音は鳴らさず、音源ファイルは配信しない。

フレームワークとビルド処理は不要。Cloudflare Workers Static Assets では `public/` を配信対象にする。
